## 2024-05-20 - Jetpack Compose Accessibility Semantics
**Learning:** In Jetpack Compose, icons used alongside informational text (like AppIcons next to AppNames) or within components that inherently manage their own state (like the 'Done' checkmark in a FilterChip) should have their `contentDescription` set to `null` to avoid redundant TalkBack announcements. Additionally, custom components acting as buttons using the `.clickable` modifier require an explicit `role = androidx.compose.ui.semantics.Role.Button` to ensure screen readers correctly interpret and announce the interaction intent.
**Action:** When implementing custom interactive elements or layout pairs (icon + text), evaluate whether the icon's description is redundant. Ensure custom clickables always carry appropriate semantic roles.
