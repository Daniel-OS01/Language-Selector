## 2024-11-08 - Fix redundant TalkBack announcements and improve AppListItem roles
**Learning:** In Jetpack Compose, when applying the `.clickable` modifier to custom components functioning as buttons, explicitly specify a semantic role (e.g., `role = androidx.compose.ui.semantics.Role.Button`) to ensure screen readers correctly announce the component's intent. Icons within components that inherently manage their own accessibility state (such as the 'Done' icon in a selected FilterChip), or decorative icons adjacent to text labels (like app icons in list items), should have their `contentDescription` set to `null` to prevent redundant TalkBack announcements.
**Action:** When implementing new custom UI components or refactoring existing ones, always consider TalkBack semantics and remove redundant descriptions.
