## 2024-07-31 - Fix redundant TalkBack announcements in Compose
**Learning:** In Jetpack Compose, icons within components that inherently manage their own accessibility state (such as the 'Done' icon in a selected FilterChip), or decorative icons adjacent to text labels (like app icons in list items), should have their `contentDescription` set to `null` to prevent redundant TalkBack announcements. Additionally, when applying the `.clickable` modifier to custom components functioning as buttons, explicitly specifying `role = androidx.compose.ui.semantics.Role.Button` ensures screen readers correctly announce the component's intent.
**Action:** Always set `contentDescription = null` for decorative icons or those paired with adjacent text, and explicitly provide semantic roles for custom `.clickable` components.
