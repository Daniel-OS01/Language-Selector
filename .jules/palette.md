## 2024-08-04 - Fix redundant TalkBack announcements in custom Compose buttons
**Learning:** In Jetpack Compose, icons within components that inherently manage their own accessibility state or are adjacent to text labels (like app icons in list items) should have their `contentDescription` set to `null` to prevent redundant TalkBack announcements. Additionally, when applying the `.clickable` modifier to custom components functioning as buttons, explicitly specify a semantic role (e.g., `role = androidx.compose.ui.semantics.Role.Button`) to ensure screen readers correctly announce the component's intent.
**Action:** Always set `contentDescription = null` for decorative icons or icons adjacent to their text equivalents, and ensure all custom `clickable` components that act as buttons have `role = androidx.compose.ui.semantics.Role.Button` assigned.
