## 2024-08-11 - Redundant TalkBack announcements in custom components
**Learning:** This app's custom UI components (like `AppListItem`, `QuickTextButton`, and selected `FilterChip` states) frequently apply string values to `contentDescription` for decorative or state-driven icons that are already adjacent to descriptive text or managed by the component itself, leading to cluttered, redundant TalkBack announcements. Additionally, custom components acting as buttons rely on `.clickable` without specifying semantic roles.
**Action:** When working on Compose components in this app, explicitly set `contentDescription = null` for icons adjacent to text labels or state icons managed by parent components, and always assign `role = androidx.compose.ui.semantics.Role.Button` to custom clickable button composables.
